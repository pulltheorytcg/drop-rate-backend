Do not use this profile for oversized, thick-card, autograph, comic, manga or
memorabilia holders. Those require separate profiles.

## Royal Mail fit

Royal Mail's Tracked 48 Large Letter maximum is 353 x 250 x 25mm and 1kg when
purchased online:

https://www.royalmail.com/sending/uk/tracked-48

The approved box is within the length, width and weight limits. Its 25mm depth is
exactly the maximum, not below it. Every packed box must therefore close flat without
tape, cushioning or contents making it bulge beyond 25mm. Anything thicker must use a
Small Parcel label.

The 164 x 116mm plan area provides substantially more clearance than the earlier
145 x 110mm raw-card package for the researched standard slab sizes.

## Dispatch quality control

1. Put the slab in a non-abrasive sleeve and prevent movement without compressing it.
2. Close the package naturally; do not force the lid down.
3. Pass the sealed package through a 25mm Large Letter gauge.
4. Weigh the completed package. Escalate any result above 120g and update the profile before dispatch.
5. Use a Small Parcel service if the package fails the thickness gauge.
6. Use a separate approved profile for non-standard holders.
7. Record actual postage during fulfilment reconciliation.

## Operational rule

Standard graded cards may now pass the shipping-profile part of Shopify completeness.
All other identity, ownership, media, pricing and publication safeguards still apply.
